# session1_assignment

## 📌 Description
This project is a simple calculator implemented in Python.

The program:
- Takes two numbers from the user
- Takes an operator (+, -, *, /, %, **)
- Performs the selected arithmetic operation
- Displays the result in a formatted way
- Handles errors such as:
  - Invalid (non-numeric) input
  - Division by zero
- Runs continuously until the user types "exit"

---

## ▶️ How to Run

1. Make sure Python is installed on your system.

2. Download or clone the repository:
 - `git clone https://github.com/FarahElwakeel/session1_assignment.git`
